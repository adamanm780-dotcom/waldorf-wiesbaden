# Waldorf Wiesbaden - Schulwebsite

## Beschreibung
Website fuer die Freie Waldorfschule Wiesbaden. Mehrseitige Website mit Unterseiten fuer Schulleben, Service-Bereiche, Termine, Offene Stellen und mehr.

## Status
In Arbeit / Fertiggestellt

## Tech-Stack
- HTML / CSS / JavaScript
- Node.js (fuer Build-Tools)
- Eigenes CSS-Framework (waldorf-shared.css, new_style.css)
